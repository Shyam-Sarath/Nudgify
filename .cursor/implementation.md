Redesign Nudgify into a premium, production-quality food marketplace inspired by the UX principles of Swiggy, Zomato, Uber Eats, and DoorDash, while maintaining its own identity as a marketplace for independent home chefs.

Do **not** clone any application's design. Instead, adopt modern UX patterns, layouts, navigation, and interactions while creating an original visual identity.

### Design Goals

* Clean
* Premium
* Fast
* Mobile-first
* Consistent
* Accessible
* Responsive
* Smooth animations

### Global Improvements

* Modern design system with consistent spacing, typography, colors, and elevation.
* Rounded cards and buttons.
* Skeleton loading states.
* Toast notifications.
* Empty state illustrations.
* Pull-to-refresh.
* Floating action buttons where appropriate.
* Smooth page transitions.
* Bottom sheets for actions instead of intrusive modals.
* Dark mode support.
* High-quality icons and subtle micro-interactions.

### Animations

Add tasteful animations for:

* Screen transitions.
* Card appearance.
* Button presses.
* Loading states.
* Success actions.
* Empty states.

Avoid excessive or distracting motion.

### Performance

Ensure the redesigned UI remains performant, reusable, component-driven, and easy to maintain.

Preserve the existing business logic wherever possible and separate presentation from functionality so backend integration remains straightforward.
